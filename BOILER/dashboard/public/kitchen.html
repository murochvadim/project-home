    ▸ Recipe quantities

    A recipe says 400 ג' of flour. The shop sells a pack. These rules turn the recipe's amount into how many to buy.

    Each row covers one unit and a range of amounts. The first row that fits wins. If no row fits, you buy 1.

    Buy is how many go on the list. Write same to use the recipe's own number. Only do that when the recipe and the shop use the same word: 2 קופסאות tuna means 2 boxes.

    Leave Unit empty for things you count one by one, like 4 תפוחי אדמה.

    Fractions become small numbers: 1/3 כוס is 0.333, 3/4 כף is 0.75, רבע צרור is 0.25. A row that starts at 1 will skip them. Start it at 0 to include them.
