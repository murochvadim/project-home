Shutdown Settings—Set by Remove / Restore SAFETY_MODE buttons

Shutdown at battery
—
trigger when battery % falls to this (BATTERYLEVEL)
Shutdown at low runtime
—
trigger when remaining runtime ≤ X min (MINUTES)
Shutdown after time on battery
—
trigger after X seconds on battery (TIMEOUT)
Mains-loss confirm delay
—
wait before declaring mains lost (ONBATTERYDELAY)
Safety mode
—
when ON, orchestrator only logs — no shutdown
UPS protection after mini-PC restart
—
when ON, the mini-PC keeps watching the UPS automatically after every reboot — no manual login needed
● Remove SAFETY_MODE → SHUTDOWN ON: during a real power cut the system gracefully shuts everything down before the battery runs out. This is the normal, protected setting — leave it here.
● Restore SAFETY_MODE → SHUTDOWN OFF: test / safe mode — during a power cut nothing shuts down, it only writes to the log. Use only while testing.
